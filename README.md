# Angel Susan Joseph — Portfolio Website

A responsive, static portfolio website built with plain HTML and CSS.

## Preview locally
Open `index.html` in a browser.

## Publish
Upload the contents of this folder to a GitHub repository and enable GitHub Pages in the repository's Settings → Pages. After publishing, use the confirmed public website URL in the resume.

## Before publishing
- Verify each project summary and employment detail.
- Add direct repository links only after confirming the correct repository for each project.
- Add a downloadable resume file if desired.
